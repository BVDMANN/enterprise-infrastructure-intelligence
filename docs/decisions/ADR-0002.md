# ADR-0002 — Stack technique fixée

- **Statut :** Accepté (2026-11-24, PHASE 0)
- **Contexte :** la spécification V3 §5 fixe la stack. Il faut la
  consigner comme décision pour empêcher toute dérive silencieuse.
- **Décision :**
  - Frontend : Next.js App Router, React, TypeScript **strict**,
    Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, Zod,
    Recharts, Lucide Icons.
  - Backend : Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2, Alembic.
  - Données : PostgreSQL 16, Redis 7, Celery.
  - Infra : Docker, Docker Compose, GitHub Actions, OpenTelemetry.
  - Tests : pytest (backend), Playwright (e2e).
- **Conséquences :**
  - Une seule stack à maîtriser par couche ; écosystèmes matures ;
    recrutement et maintenance facilités.
  - TypeScript strict et Pydantic imposent une discipline de typage
    qui sert la fiabilité et la sécurité (validation des entrées).
- **Alternatives rejetées :** toute autre stack sans ADR préalable.
- **Règle :** toute modification de stack exige un nouvel ADR
  (problème, conséquences, solution justifiée) — jamais de changement
  silencieux.
